# Подключение

Плата: обычный ESP32 DevKit (ESP32-D0WD, 4 МБ). Все номера GPIO заданы в `firmware/mic_stream/config.h`.

| Что | Вывод ESP32 | Примечание |
|---|---|---|
| INMP441 SCK | GPIO26 | такт битов (I2S BCLK) |
| INMP441 WS | GPIO25 | выбор канала (LRCLK) |
| INMP441 SD | GPIO33 | выход данных микрофона |
| INMP441 L/R | GND | левый канал; на VDD будет правый |
| INMP441 VDD / GND | 3V3 / GND | **только 3,3 В** |
| Кнопка записи | GPIO27 → кнопка → GND | подтяжка внутренняя; контакты COM и NO |
| Кнопка «следующая запись» | GPIO13 → кнопка → GND | |
| Светодиод «есть новые» | GPIO18 → 330 Ом → светодиод → GND | горит, пока есть непрослушанные |
| Выход под подсветку кнопки | GPIO4 | мигает во время записи; к подсветке 12 В только через MOSFET (например IRLZ44N), общая земля |
| Встроенный светодиод платы | GPIO2 | горит во время записи |
| MAX98357A BCLK / LRC / DIN | GPIO21 / GPIO19 / GPIO22 | |
| MAX98357A VIN / GND | 5V / GND | к усилителю динамик 4–8 Ом |
| MAX98357A SD | GPIO23 | необязательно: усилитель выключается в тишине (нет шипения). Не подключён: усилитель всегда включён |

## Кнопка записи (аркадная, 46 мм)

Купол 46 мм, резьба M24 × 2 (отверстие в корпусе около 24,5 мм), внутри микропереключатель и подсветка 12 В. Для сигнала
3,3 В нужны только контакты COM и NO. Подсветку 12 В напрямую от платы подключать нельзя: она включается через MOSFET с GPIO4.

## Питание от аккумулятора 18650

```
USB-C → TP4056 (с защитой) B+/B− → 18650
              OUT+ → выключатель ─┬→ MT3608 (выставить 5,0 В!) → ESP32 VIN
                                  ├→ MAX98357A VIN
                                  └→ 100k ─ GPIO34 ─ 100k → GND
```

MT3608 с завода может выдавать 12–28 В: настройте 5,0 В мультиметром до подключения платы. Делитель на GPIO34 даёт процент
заряда в Пульте и предупреждение в Telegram при 15 %. Без делителя Пульт показывает «от USB».

## Безопасные выводы ESP32

Не использовать под свои нужды: GPIO0, 2, 5, 12, 15 (влияют на загрузку), GPIO34–39 (только вход, без подтяжки), GPIO6–11 (флеш).
