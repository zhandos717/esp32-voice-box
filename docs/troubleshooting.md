# Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| `Wi-Fi disconnected, reason 15` (или 202) | неверный пароль Wi-Fi. Введите заново: `python tools/set_wifi.py COM11 --show` |
| `reason 201` | сеть не найдена, либо она только на 5 ГГц (ESP32 работает на 2,4 ГГц) |
| `NO WIFI SETTINGS` | настройки ещё не записаны: запустите `tools/set_wifi.py` |
| Плата в Wi-Fi, но на сервер не подключается | брандмауэр Windows не пропустил порт 8800: разрешите программе доступ в частных сетях; проверьте адрес ПК в `set_wifi.py` |
| Микрофон шумит без пауз, пики на полной шкале | SD-провод не на GPIO33 («висит в воздухе») или L/R не на GND |
| Записи короче, чем держали кнопку | смотрите журнал сервера: строки `board:` показывают, через сколько пришла команда старта и сколько звука ушло |
| Открытие порта перезагружает плату | так делает USB-мост CH340: после открытия COM-порта подождите, пока плата снова подключится |
| `recording too short, dropped` | касание кнопки короче 0,3 с, это нормально |

Журнал сервера: `server.log` рядом с программой (если запускали с перенаправлением вывода). Журнал платы: последовательный порт 115200.
